# 希腊神话家族谱系

以交互式家族树浏览希腊神话中的神祇与英雄。项目为纯前端静态网页，无需安装、后端或登录。

**在线入口：[希腊神话家族谱系](https://wyihao2010-code.github.io/Theogony/)**

## 两部谱系

- **[神谱](https://wyihao2010-code.github.io/Theogony/gods.html)**：以赫西俄德《神谱》的文本顺序为主线，从卡俄斯追溯原初神、泰坦、海神与奥林匹斯众神及其重要分支。
- **[英雄谱](https://wyihao2010-code.github.io/Theogony/heroes.html)**：依据荷马史诗、阿波罗多洛斯《书库》和古典悲剧中的通行说法，梳理珀尔修斯与赫拉克勒斯、忒修斯、忒拜王室、特洛伊战争等英雄家族。

不同古典文献对部分人物的出身或世系有不同记载，相关差异与取舍见人物详情及页面底部说明；图中的代际排列用于阅读，不代表精确年表。

## 使用方法

- **浏览与定位**：拖动画布平移；使用鼠标滚轮、触控板捏合或右下角按钮缩放；点击缩放百分比可回到默认视图。
- **查找人物**：在顶部搜索框输入姓名；也可通过分支按钮或图例筛选。
- **查看关系与详情**：单击人物高亮其关联关系，双击聚焦家族分支；电脑端右键人物、手机端长按人物后松手，可查看详情。
- **页面切换**：使用页头的“返回首页”或切换按钮，在门户和两部谱系之间导航。

触屏长按不触发页面振动；画布拖动时阻止浏览器原生拖拽。字体使用 Google Fonts，断网时回退到系统字体。

## 文件与本地运行

| 文件 | 内容 |
| --- | --- |
| `index.html` | 两部谱系的门户 |
| `gods.html` | 神谱 |
| `heroes.html` | 英雄谱 |
| `tests/test_site.py` | 入口及页面导航检查 |

直接用浏览器打开 `index.html` 即可使用。运行导航检查：

```sh
python3 -m unittest discover -s tests -v
```

每部谱系均为独立 HTML，包含页面样式、人物数据与交互代码；图谱使用 DOM、SVG 和 Canvas。人物及世系数据可以继续补充。
